1. IES Zonal Cavity Ceiling Lighting & Obstruction Geometry

Dividing room area by bulb wattage ignores ceiling cavity absorption, wall reflectance, and beam cone overlap. The Illuminating Engineering Society (IES) Zonal Cavity method computes Room Cavity Ratio (RCR) first:

RCR = (5 * h_cavity * (Length + Width)) / (Length * Width)
h_cavity = Ceiling_Height - Workplane_Height
Fixtures_Required = ceil((Target_FC * Area_SqFt) / (Lumens_Per_Fixture * CU * LLF))

2. 2024 IRC R312.1.3 Guardrail, Stair Rake & R507.5 Framing Formulas

To eliminate cumulative spacer-block drift and pass municipal framing inspection under the 4-inch sphere rule (level rails) and 6-inch stair triangle rule, pull continuous leading-edge marks from inside post face 0":

Baluster_Count (N) = ceil((Clear_Span - Max_Gap) / (Baluster_Width + Max_Gap))
Exact_Horiz_Gap (g) = (Clear_Span - N * Baluster_Width) / (N + 1)
Horiz_Leading_Edge[i] = g + (i - 1) * (g + Baluster_Width)

// Angled Stair Rake (Unit Rise R, Unit Tread Run T, Pitch theta = atan(R / T)):
Sloped_Shoe_Rail_Mark[i] = Horiz_Leading_Edge[i] / cos(theta)
Spindle_Sloped_Footprint = Baluster_Width / cos(theta)
